## 🌟 About the Project

**Netflix Clone** is a front-end web development project inspired by the Netflix streaming platform. It recreates a modern entertainment browsing experience using HTML and CSS, with a dark cinematic theme, a featured *Stranger Things* banner, movie posters, TV show collections, a video player, and an expandable FAQ section.

This project demonstrates my understanding of responsive web design, semantic HTML, CSS Flexbox, CSS Grid, animations, transitions, and modern UI styling.

## ✨ Features

- 🎬 **Featured Hero Banner** — A cinematic *Stranger Things* section with a background image, description, and action buttons.
- 🔥 **Trending Now** — A horizontally scrollable collection of popular titles.
- 📺 **Popular TV Shows** — A dedicated section showcasing TV series.
- 🍿 **Popular Movies** — Movie cards featuring posters, titles, and genres.
- ▶️ **Video Trailer Player** — HTML5 video playback with native controls.
- ❓ **Interactive FAQ** — Expandable questions and answers using native HTML elements.
- 🔍 **Search Interface** — A styled search bar in the navigation area.
- 🎨 **Netflix-Inspired Theme** — A dark interface with signature red accents.
- ✨ **Smooth Animations** — Hover effects, image zoom, and entrance animations.
- 📱 **Responsive Design** — Layout adjustments for desktop, tablet, and mobile screens.
- 🧭 **Navigation Bar** — Links to different sections of the website.
- 🖼️ **Movie Poster Cards** — Attractive poster layouts with titles, genres, and rankings.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the repository

Open your terminal and run:

```bash
git clone https://github.com/shreyashrastogi12-hub/Netflix-Clone.git
```

### 2. Navigate to the project folder

```bash
cd Netflix-Clone
```

### 3. Open the project

Open the project folder in Visual Studio Code or your preferred code editor.

Make sure the HTML file, CSS stylesheet, movie poster images, and trailer video are available in the locations referenced by the code.

### 4. Run the website

Open `index.html` in your web browser.

You can also use the Live Server extension in Visual Studio Code for a convenient local preview.

**You're ready to explore the Netflix-inspired interface!** 🎉
